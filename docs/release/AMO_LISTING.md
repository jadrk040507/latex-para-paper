## Name
LaTeX Shortcuts

## Summary
Write LaTeX faster in Dropbox Paper with keyboard shortcuts.

## Description
Expand LaTeX shortcuts as you type in equations in Dropbox Paper. Type `//` to create a fraction, then use Tab and Shift+Tab to move between fields. The shortcut catalog includes symbols, roots, integrals, matrices, and a searchable reference. Enable or disable shortcuts from the extension menu. Settings are stored locally. Firefox asks before granting the extension access to Dropbox.

This experimental beta supports desktop Firefox and Dropbox Paper on `www.dropbox.com`. A Dropbox account with Paper access is required. Google Docs and other editors are not supported. The commands Paper renders depend on Paper’s own TeX support. The project is independent and is not affiliated with Dropbox or Obsidian.

## Privacy
The extension processes shortcut input locally. It does not send document contents to an extension server and includes no analytics. It stores only activation preferences. The optional diagnostic runs on request and reports editor structure without document text. Dropbox’s own processing and storage are governed by Dropbox.
