# LaTeX Shortcuts — Privacy Policy

Effective date: October 1, 2026.

LaTeX Shortcuts expands LaTeX keyboard shortcuts in Dropbox Paper and Overleaf Code Editor. This policy covers the extension, independently of those services.

## Editor content and tab addresses

With your permission to access a supported site, the extension reads source text and cursor/selection positions in the supported editor and processes them in memory to expand shortcuts and navigate fields. Overleaf integration can read the open source document; Paper integration reads the active native equation input and, for mk/dm entry, the relevant prose context. This processing happens locally in your browser.

When you open the extension menu, it checks the current tab’s address to choose connection controls and request the correct site permission. It does not request browser-history access or keep a record of websites you visit.

The extension does not transmit document text or tab addresses to the developer or an extension backend. It does not log or persist document text, include analytics or advertising, sell user data, or use content or addresses for unrelated purposes. Edits are made in the host editor; Dropbox and Overleaf may synchronize those edits under their own terms and privacy policies.

## Local settings

The extension saves the enabled/paused preference in your browser’s local extension storage. Earlier versions may have left unused per-site activation preferences; the current version ignores them. These settings are not sent to the developer. Uninstalling the extension removes its local extension storage through the browser.

## Optional diagnostic

If you choose Inspect editor, the extension shows a local structural report including the editor’s tag, filtered CSS classes, supported attributes and host name. It excludes document text, field values, passwords and author identifiers. The report is not automatically transmitted. If you manually share it in a support request, it is shared with the recipient you choose.

## Permissions and controls

Site permissions are optional. You can pause shortcut processing with the single switch in the menu, revoke site permissions in the browser’s extension settings, or uninstall the extension. It does not read authentication cookies or collect account credentials, payment details, or personal identifiers as separate data categories.

The extension uses content and the current tab address only to provide the shortcut and connection features described here. It does not transfer this data for advertising, sale, creditworthiness or lending decisions.

## Third-party services

Dropbox, Overleaf, the browser, Chrome Web Store, and GitHub have their own privacy policies. Opening an external shortcut-support link or manually submitting an issue is subject to the destination service’s policies.
